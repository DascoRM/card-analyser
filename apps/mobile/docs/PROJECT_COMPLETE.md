## 🎯 Grading System

### Four Criteria Evaluated

1. **Borders (25%)**
   - Edge uniformity detection
   - Border thickness consistency
   - Scored 0-10

2. **Defects (30%)** - Highest weight
   - Surface scratch detection
   - Stain identification
   - Scored 0-10

3. **Centering (25%)**
   - Symmetry measurement
   - Alignment analysis
   - Scored 0-10

4. **Cut Quality (20%)**
   - Edge straightness
   - Corner sharpness
   - Scored 0-10

### Final Grade Calculation
```
Final Grade =
  (Borders × 0.25) +
  (Defects × 0.30) +
  (Centering × 0.25) +
  (Cut Quality × 0.20)

Result: 1.0 - 10.0
```

### Grade Scale
- **10.0**: Gem Mint - Perfect
- **9.0-9.5**: Mint - Near perfect
- **8.0-8.5**: Near Mint/Mint - Excellent
- **7.0-7.5**: Near Mint - Very good
- **6.0-6.5**: Excellent - Minor wear
- **5.0-5.5**: Very Good - Moderate wear
- **4.0-4.5**: Good - Noticeable wear
- **3.0-3.5**: Fair - Significant wear
- **2.0-2.5**: Poor - Heavy wear
- **1.0-1.5**: Poor - Damaged

## 🎨 Customization

### Easy Changes

**1. Change colors**
Search and replace in screen files:
```typescript
// Primary green
'#4CAF50' → YOUR_COLOR

// Light green
'#8BC34A' → YOUR_COLOR
```

**2. Adjust grading weights**
Edit `src/constants/grading.ts`:
```typescript
export const CRITERIA_WEIGHTS = {
  BORDERS: 0.25,      // Adjust these
  DEFECTS: 0.30,      // Must sum to 1.0
  CENTERING: 0.25,
  CUT_QUALITY: 0.20,
};
```

**3. Modify grade scale**
Edit `getGradeLabel()` in `src/constants/grading.ts`
